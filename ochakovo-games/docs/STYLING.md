# Стилистика ОЧАКОВО

Описание визуального языка и дизайна-системы бренда ОЧАКОВО на основе фирменного брендбука.

## Типографика

### Фирменный шрифт

Гарнитура бренда ОЧАКОВО — **Proxima Nova**. Данная гарнитура имеет широкий спектр начертаний для различного вида оформления текстовых информаций.

Использование исключительно данной гарнитуры позволяет достичь единого визуального образа и обеспечить более четкую идентификацию бренда.

#### Доступные начертания

- Proxima Nova Thin
- Proxima Nova Light
- Proxima Nova Regular
- Proxima Nova Semibold
- Proxima Nova Bold
- Proxima Nova ExtraBold

**Примечание:** Правообладателем гарнитуры Proxima Nova является Mark Simonson. Приобретение многопользовательской лицензии возможно по адресу [www.paratype.ru](https://www.paratype.ru).

#### Рекомендации по использованию

Приведенные шрифтовые гарнитуры рекомендуется использовать при оформлении текстовых блоков в деловой документации, информационных изданиях, интернет-проектах, корпоративной продукции и рекламных макетах. Для набора текста в официальной деловой документации (например, письма, служебные соответствия, электронные письма и т.п.), рекомендуется использовать системную шрифтовую гарнитуру Tahoma в различных начертаниях.

## Пиктограммы

Специально для фирменного стиля ОЧАКОВО были разработаны уникальные пиктограммы, иллюстрирующие процессы производства, оборудование, продукцию и ее ингредиенты/сырье.

Все пиктограммы выдержаны в единой иллюстрационной стилистике и имеют одинаковую толщину линий.

**На данной странице демонстрируется набор пиктограмм для оформления корпоративных носителей.**

Существуют также наборы пиктограмм, предназначенные для оформления носителей, относящихся к другим областям фирменного стиля (HR и Retail).

### Правила использования пиктограмм

Пиктограммы могут быть использованы по отдельности, сопровождая/иллюстрируя тестовые блоки и составляться в группы, помощью оформляя повествовательность носителей.

Для удобства работы каждая пиктограмма зафиксирована в определенном месте квадратного модуля (в прилагаемых файлах каждая пиктограмма сгруппирована в модулю, не имеющему заливки и окантовки).

При создании групп или разделении носителей рекомендуется соблюдать единый масштаб пиктограмм, либо отдельно до целых пиктограмм допускается использование прямоугольничков ближайших по форме к квадрату.

**В случае создания групп обязательно должны соблюдаться единый масштаб пиктограмм и цвет, а также рекомендуется в составе группы включать пиктограммы разных жанров (Сырье, производство, продукция).**

## Паттерны

Трансформирующие паттерны являются инструментами для более разнообразного оформления носителей фирменного стиля.

За основу при оформлении носителей могут быть взяты обе части паттерна или только одна.

Для более гибкого применения паттерны могут трансформироваться за счет прибавления или удаления рядов или столбцов в группах пиктограмм.

### Правила трансформации

- Столбцы убираются или добавляются только с левой стороны каждой из частей паттерна, ряды — сверху и справа.
- Прибавление столбцов допускается только под новыми столбцами.
- Максимальное количество рядов в паттерне — 8, минимальное — 2.
- Максимальное количество столбцов в каждой из двух частей паттерна — 10, минимальное — 3.
- **Не рекомендуется использовать одновременно максимальное количество столбцов и рядов и одновременное минимальное их количество.**
- При добавлении рядов и столбцов необходимо придерживаться принципов составления групп пиктограмм, используя их модули.
- При добавлении пиктограмм необходимо следить за тем, чтобы рядом не находились одинаковые пиктограммы.

## Квадратные модули

В рамках фирменного стиля разработан принцип оформления носителей с помощью равных квадратных модулей.

Данный принцип может быть применен как ко всей поверхности носителя, так и к его части (например, шевром, квадратная визитная карточка, приглашательный билет, блок-фотография и т.п.).

### Рекомендации при применении

- Рекомендуется составлять группы или разделить носитель на более чем на 3 раза из 3 столбца модулей.
- При необходимости нахождения рядом модулей могут быть объединены в один.
- В некоторых случаях формат носителя невозможно разделить на квадраты, допускается использование прямоугольничков ближайших по форме к квадрату.
- Модули окрашиваются в цвета фирменной цветовой палитры.
- При напряжении модуля текстовой информацией необходимо по всему его периметру оставлять равномерное свободное пространство.

### Цветовые сочетания

На схеме представлены возможные цветовые сочетания фона и пиктограмм с использованием фирменной цветовой палитры.

**Активные** — для создания ярких комбинаций, привлекающих внимание.

**Средней активности** — нейтральное использование квадратных модулей при наличии визуального баланса с другими элементами композиции.

**Неактивные** — для создания фоновых (менее броских) комбинаций.

## Стилеобразующие элементы

Стилеобразующие элементы являются инструментами для более разнообразного оформления носителей фирменного стиля.

К ним относятся: набор пиктограмм, фирменные паттерны, квадратные модули и заливки фирменного красного цвета.

С их помощью возможно добиться как активного, так и более сдержанного оформления носителей в зависимости от решаемой задачи.

Например, такие носители как наружная реклама, рекламные модули, обложки, штучные плакаты требуют акцентированного, яркого оформления, а носители типа деловых документов, внутренних разработок изданий и т.п. необходимо легкое декорирование.

Каждый из декоративных элементов имеет правила и рекомендации по использованию, они представлены далее в разделе.

## Заливки

Заливки — это оформление носителей посредством их окрашивания в фирменные цвета.

Красный цвет является основным идентификатором фирменного стиля ОЧАКОВО.

Заливки красного цвета необходимо разбавлять белым.

Рекомендуется окрашивать либо всю поверхность носителя целиком, не оставляя рамок по краям, либо отдельную его деталь/часть.

## Применение в дизайн-системе проекта

При оформлении интерфейса мини-игр «Профессии» и других проектов ОЧАКОВО используются основные элементы фирменной стилистики:

- **Основной цвет** (красный #CD004B) — для CTA-кнопок, акцентов, логотипа.
- **Вторичные цвета** (белый, серый, темно-серый) — для фонов, текстов и вспомогательных элементов.
- **Типографика** (Proxima Nova) — для заголовков и основного текста.
- **Пиктограммы** — в интерфейсе игр, меню, информационных блоках.
- **Паттерны** — декоративные фоны, разделители, украшающие элементы.
- **Квадратные модули** — для создания структурированных блоков контента, сеток.

Все элементы должны работать согласованно, создавая единый, узнаваемый визуальный язык бренда ОЧАКОВО.

# Тестирование в Telegram

Telegram открывает мини-приложение только по **HTTPS**, поэтому для теста нужна выкладка сборки
(`npm run build` → папка `dist/`) на любой HTTPS-хостинг.

## 1. Бот и мини-приложение (один раз)

1. В Telegram открыть [@BotFather](https://t.me/BotFather) → `/newbot`, задать имя и username.
2. `/newapp` → выбрать бота → название, описание, картинка 640×360 → **адрес** (хостинга) → короткое имя, например `game`.
   Получится ссылка `https://t.me/<bot>/game` — её можно отправить тестировщикам.
3. Дополнительно (кнопка в чате с ботом): `/mybots` → бот → **Bot Settings → Menu Button** → тот же адрес.

Сменить адрес потом: `/myapps` → приложение → **Edit Web App URL**.

## 2. Что проверять

Режим приложения в Telegram включается сам: сразу открывается карта профессий, без лендинга.
В браузере то же самое — по адресу `/?app`.

| Параметр | Где | Что делает |
|---|---|---|
| `?app` | браузер | игра без лендинга, как в Telegram |
| `?unlock` | браузер | открыть все главы и уровни |
| `?debug` | браузер | консоль разработчика на экране (eruda) |
| `?startapp=debug` | ссылка `t.me/<bot>/game?startapp=debug` | eruda внутри Telegram |

Чек-лист (из `docs/PLAN.md`, п. 7):

- [ ] Свайп вниз по экрану не сворачивает приложение
- [ ] Системная кнопка «Назад» в шапке Telegram: глава → карта, уровень → пауза, брифинг → уровни;
      на карте её нет
- [ ] Своей кнопки «назад» в интерфейсе нет (в браузере есть)
- [ ] Вибрация на нажатия и итог уровня
- [ ] Цвет шапки Telegram совпадает с фоном игры
- [ ] Приветствие по имени на карте
- [ ] Прогресс сохраняется: пройти уровень, закрыть, открыть снова
- [ ] Прогресс переносится: пройти на телефоне → открыть в Telegram Desktop
- [ ] Свернуть приложение во время уровня → пауза
- [ ] Ничего не прячется под вырезом экрана и полоской «домой» (iPhone)
- [ ] Светлая и тёмная тема Telegram: игра выглядит одинаково

Устройства: iPhone, Android (средний и слабый), Telegram Desktop, Web (web.telegram.org/k и /a).

## 3. Отладка

- **`?startapp=debug`** — самый простой способ: консоль и ошибки прямо на экране телефона.
- **Android:** Telegram → Настройки → долгое нажатие на номер версии внизу → *Enable WebView Debug*,
  затем в Chrome на ПК `chrome://inspect` (телефон по USB).
- **iOS:** Настройки → Safari → Дополнения → *Веб-инспектор*; на Mac Safari → Разработка → телефон.
- **Telegram Desktop:** Настройки → Продвинутые → Экспериментальные → *Enable webview inspection*,
  затем правый клик внутри приложения → Inspect.

## 4. Как это устроено в коде

- `src/platform/` — всё, что зависит от площадки: хранилище, вибрация, кнопка «назад», пауза при сворачивании.
  `telegram.ts` — Telegram, `web.ts` — обычный сайт. Игра работает только с интерфейсом `Platform`.
- Telegram распознаётся по параметрам в адресе (`#tgWebAppData=…`). Только тогда загружается
  `public/telegram-web-app.js` — копия официального скрипта (с telegram.org он грузится медленно).
  Обновлять копию: `curl -o public/telegram-web-app.js https://telegram.org/js/telegram-web-app.js`.
- Прогресс: сначала с устройства (мгновенно), затем подмешивается Telegram CloudStorage —
  по каждому уровню берётся лучший результат.
- Отступы под вырез и панели Telegram — CSS-переменные `--safe-*` (`src/index.css`, класс `.tg`).

# Диалоги

Каждый файл `*.txt` — один диалог. Редактируйте текст прямо здесь, код менять не нужно
(при запущенном `npm run dev` изменения подхватываются сразу).

Формат:

- Строка `# Имя` задаёт говорящего. Её можно повторять в середине файла — дальше говорит другой персонаж.
- Реплики разделяются пустой строкой. Одна реплика — одно нажатие. Перенос строки внутри реплики считается пробелом.
- Строки, начинающиеся с `//`, — комментарии, в игре их нет.

Файлы подключаются по имени (без `.txt`): `глава-1-уровень-1`, `глава-1-уровень-2`, `глава-1-уровень-3` (цех), `глава-1-уровень-3-пресс`, `глава-1-уровень-3-ошибки`, `склад-уровень-1`, `пролог`.
